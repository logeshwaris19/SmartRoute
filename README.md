# 🚌 SmartRoute – Intelligent Transit System

SmartRoute is a web-based intelligent transit system designed to help users find bus routes, check route details, and track buses in real time.

The project provides a simple, responsive, and professional interface for passengers to search routes and access transit information.

## 🚀 Features

- 🔎 Search bus routes using **From** and **To** locations
- 🚌 Display available bus routes
- ⚡ Fastest route filter
- 💰 Route comparison without fare display
- 🔄 Swap From and To locations
- 📍 Live bus tracking
- 📊 User dashboard
- 🔐 Login system
- 👨‍💼 Admin dashboard
- 📱 Responsive design for desktop and mobile
- 💾 LocalStorage-based route and tracking data
- 🎨 Modern and professional UI
